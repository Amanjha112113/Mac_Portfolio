# Aman Jha — macOS AI Portfolio 

A state-of-the-art, high-fidelity macOS Sequoia desktop experience built with **Next.js 16**, **TypeScript**, **Framer Motion**, and **Vanilla CSS**. Features an Apple Intelligence-inspired Realtime Voice AI Assistant, dynamic window management, multi-modal applications, and full offline/PWA capabilities.

---

## 🌟 Key Features

- ** Native macOS Experience**: Full window management (drag, resize, maximize, minimize, cascade, z-index stacking), dock magnification, menu bar status items, Spotlight Search (`Cmd+K`), and Context Menu.
- **✨ Apple Intelligence Voice AI**: Realtime Voice AI engine with multi-layered glowing mesh orb visualizers, Web Speech API integration, synchronized speech synthesis (TTS), live audio equalizers, and sub-200ms interruption barge-in.
- **🛠️ Agentic Tool Execution**: Voice Assistant autonomously controls macOS apps (Finder, Terminal, Music, Safari, Messages, Notes, System Settings) and dynamically switches desktop wallpapers.
- **💎 Liquid Glassmorphic Aesthetic**: Ultra-refined frosted blur backgrounds, native macOS icons, smooth spring physics with Framer Motion, and high-DPI custom wallpaper engine.
- **📱 Responsive & Accessible**: Supports desktop interactions, mobile touch fallback, keyboard navigation shortcuts, and high contrast modes.

---

## 🚀 Featured Applications

1. **Finder**: Multi-pane file explorer showcasing featured AI/ML engineering projects (Speaker Recognition, Drowsy Driving Detection, Talent Intelligence Agent, Realtime Voice AI).
2. **Aman AI (Voice Assistant)**: Realtime conversational AI with streaming token responses and WebRTC telemetry HUD.
3. **App Store**: Paginated interactive app discovery center with smooth sliding transitions.
4. **Terminal**: Interactive macOS zsh terminal environment with simulated system commands (`help`, `projects`, `skills`, `clear`, `neofetch`).
5. **System Settings**: macOS Ventura/Sequoia style configuration center for viewing background, education, experience, and downloading official resumes.
6. **Safari, Music, Messages, Notes, Photos, Calendar, Maps**: Fully interactive standalone apps.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router, Webpack)
- **Language**: TypeScript (Strict mode)
- **Styling**: Vanilla CSS, TailwindCSS utilities
- **State Management**: Zustand
- **Animations**: Framer Motion
- **Testing**: Vitest
- **Audio & Media**: Web Speech API, Web Audio API, WebRTC Transport Layer

---

## 💻 Getting Started

```bash
# Clone the repository
git clone https://github.com/Amanjha112113/Mac_Portfolio.git

# Install dependencies
npm install

# Run the development server
npm run dev

# Run unit tests
npm test

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) in your browser to explore the portfolio.
